Algorithm Pseudocode
function findMiddle(head):
slow = head
fast = head
// First middle (for even length)
while fast.next != null and fast.next.next != null:
// Second middle (for even length)
while fast != null and fast.next != null:
slow = slow.next
fast = fast.next.next
return slow // middle node

Key insight: When fast reaches the end, slow is at the middle because fast moves twice as fast.

First vs Second Middle: For even-length lists, there are two "middle" elements. The while condition determines which one we find.
